# POMP 빠른 시작

설치부터 첫 질문, 첫 코드 변경, 에이전트 위임까지 10분 안에 따라 할 수 있는 순서다. 화면 각 부분의 설명은 [화면 가이드](screen-guide.md).

## 1. 설치

1. VS 버전에 맞는 VSIX를 준비한다.
   - VS 2017 15.9: `Pomp.VS2017-<버전>.vsix`
   - VS 2019 16.10 이상: `Pomp.VS2019-<버전>.vsix`
   - VS 2022·2026: `Pomp.VS2022-<버전>.vsix`
   - 직접 빌드: `powershell -NoProfile -File build\build.ps1` → `artifacts\` ([개발 문서](development.md#빌드))
2. Visual Studio를 모두 닫고 VSIX를 더블클릭한다. VSIX Installer가 끝나면 VS를 다시 연다.
3. 채팅 화면에는 WebView2 Runtime이 필요하다. 없으면 POMP 창에 설치 안내가 나온다.

따로 설치할 것은 없고 터미널도 필요 없다.

## 2. POMP 열기

다음 중 하나로 연다.
- **보기 > 다른 창 > POMP**
- **도구 > POMP > POMP 열기**
- `Shift+Alt+Q` (도구 › 옵션 › Pomp › 일반 › 단축키에서 바꿀 수 있다)

POMP 창은 다른 도구 창처럼 원하는 곳에 끌어 붙일 수 있다. 편집기 오른쪽에 세로로 길게 두면 쓰기 편하다.

## 3. 모델 공급자 연결

처음 열면 **계정** 탭이 열린다. 둘 중 하나로 연결한다.

- **구독 계정으로 로그인** — **계정 추가**의 공급자 타일(OpenAI · Anthropic · Muse Code · Google Antigravity가 먼저, 나머지는 검색)을 누른다.
  브라우저가 열리고, 로그인하면 POMP로 돌아온다. 코드를 붙여 넣으라는 공급자는 화면의 입력란에 붙여 넣는다.
- **API 키로 연결** — **+ 키 추가**에서 공급자를 고르고 키를 넣는다. 키는 이 PC에 암호화해 저장한다.
- **직접 띄운 모델 서버** — **+ 키 추가**의 공급자에서 **로컬 모델 서버**를 고르고 이름과 서버 주소(OpenAI 호환 주소, 예: `http://127.0.0.1:8000/v1`)를
  넣는다. 키가 필요 없는 서버면 API 키는 비워 둔다. 저장한 뒤 POMP를 다시 시작하면(오른쪽 위 `⋯` › **다시 시작**) 그 서버의 모델이 모델 목록에 그 이름으로 나온다.

연결되면 오른쪽 위 연결 점이 초록색이 된다. 여러 공급자를 연결해 두면 채팅과 에이전트마다 다른 모델을 쓸 수 있다.

## 4. 편집기에서 첫 질문

1. 솔루션을 열고 코드 파일에서 메서드 하나를 선택한다.
2. 우클릭 → **POMP > 이 코드 설명**, 또는 `Shift+Alt+E`.

![편집기 우클릭 메뉴](media/editor-menu.png)

POMP 창의 채팅 탭에 질문과 답이 나온다. 질문 아래 칩(`OrderService.cs · 20–43행`)은 함께 보낸 편집기 위치다.

![선택한 코드 설명](media/chat-explain.png)

같은 메뉴에서 **이 코드 리뷰**(`Shift+Alt+R`), **이 코드 고치기**(`F`), **테스트 작성**(`U`)도 쓸 수 있다. 메뉴 맨 위의
**POMP에게 질문**(`Alt+M`)은 선택 영역에 대한 질문이나 바꿀 지시를 바로 입력한다.

## 5. 채팅으로 묻기

입력창에 쓰고 `Enter`로 보낸다(`Shift+Enter`는 줄바꿈; 도구 > 옵션 > Pomp > 일반 > 단축키에서 `Ctrl+Enter` 전송으로 바꿀 수 있다).

- 입력창 위의 `@`로 파일·폴더·심볼을 멘션하거나, 클립 아이콘으로 파일을 첨부한다(개수 제한 없음).
- 상단 대화 목록에서 대화를 삭제할 수 있다. 한 번 더 확인하며 현재 대화면 새 대화를 먼저 시작한다.
- 옵션 **입력 예측 문장**을 켜면 입력을 잠시 멈췄을 때 이어질 문장을 보여 준다. `Tab`으로 받고 `Esc`나 다른 입력으로 지운다.
- `/`를 치면 명령 목록이 나온다: `/new` 새 대화, `/sessions` 대화 목록, `/model` 모델, `/compact` 대화 압축, `/help` 전체 목록.
- 입력창 아래에서 권한 모드(`항상 묻기` · `쓰기 자동` · `모두 자동`), 보낼 대상, 모델, 추론 단계(뇌 아이콘), fast 모드(번개)를 바꾼다.
- 응답 중에 보내면 대기열에 들어가 응답이 끝난 뒤 차례로 실행된다. `■`은 지금 응답을 멈춘다.

## 6. 코드 고치기와 승인

"이 메서드의 null 처리를 고쳐 줘"처럼 변경을 요청하면, 에이전트가 파일을 바꾸기 전에 대화 맨 아래에 **승인 카드**가 나온다.
카드에 포커스가 있을 때 `Enter`가 허용, `Esc`가 거부이고, 어디서나 `Alt+A`/`Alt+D`로 답할 수 있다.

- 카드에는 바꿀 내용이 Diff로 나온다. 확인하고 **허용**하면 그 내용 그대로 편집기 버퍼에 들어간다.
- **거부**하면 아무것도 바뀌지 않는다. VS 도구(편집·빌드 등)의 카드에는 이유 입력란이 있어, 적은 이유가 에이전트에게 전달된다.
- **이 세션 동안 허용** / **항상 허용**은 그 도구의 모든 요청을 다시 묻지 않는다. 카드에 적용 범위가 적혀 있다.
- 적용된 변경은 파일마다 `Ctrl+Z` 한 번으로 되돌린다. 저장은 직접 한다(POMP는 자동 저장하지 않는다).
- 여러 파일에 걸친 제안은 **작업 탭 › 변경 › 대기 중**에서 줄 단위로 골라 적용할 수 있다.

빌드, 테스트 실행, 셸 명령, Git 커밋·푸시, NuGet 변경, 디버거 조작도 같은 방식으로 먼저 묻는다.

## 7. 에이전트에게 맡기기

채팅 상단 대화 상대 탭 줄의 `+`를 누르고 역할(예: **검토**)을 고르면 그 에이전트와만 대화하는 탭이 열린다.

![승인 카드](media/approval-card.png)

에이전트 탭에 보낸 메시지는 POMP가 그 에이전트를 하위 에이전트로 실행해 전달한다. 실행 전에 "하위 에이전트에게 작업 맡기기" 승인
카드가 대화 안에 나온다(위 그림: 에이전트 `검토`). 코드 편집기에서는 우클릭 **POMP ▸ 에이전트·팀에게**로 선택한 코드를 바로 그
에이전트·팀에게 보낼 수 있다. 허용하면 그 에이전트는 끝날 때까지 도구별로 다시 묻지 않고 진행한다 — 그 에이전트가 다시 다른
에이전트에게 일을 맡기는 것도 포함된다(아래 그림: 검토 에이전트가 scout에게 확인을 맡기고 결과를 받아 답했다).

![에이전트 위임 결과](media/partner-delegation.png)

- 진행 상황은 채팅의 해당 **작업 카드**와 에이전트·팀 대화 상대 탭에서 본다. 구성원별 상태·도구 수·시간·최근 도구와 **중지**가 있다.
  개별 중지는 같은 줄에서 한 번 더 확인하고 그 구성원만 멈춘다.
- 새 역할이나 팀은 **에이전트 탭 › 역할 / 팀**에서 만든다. 역할마다 모델·추론 단계·도구 범위를 정할 수 있다. 대화를 지켜보는 조언자는
  **조언자**, 이벤트 규칙·프로젝트 훅은 **자동화**에서 관리한다.

## 8. 진행 확인

- **작업 탭**: **진행**(계획·워크플로·자동 계속), **변경**(**대기 중** 제안·격리 결과, **적용됨** 기록과 되돌리기), **코드 점검**(에이전트
  리뷰 지적·VS 컴파일러 오류·경고). 항목을 고르고 **에이전트에게 해결 요청**으로 현재 보낼 대상에 한 메시지로 보낸다(편집기 컨텍스트
  없음, 최대 50개·12,000자). 변경 칩 숫자는 대기 항목만 센다.
- 하위 화면 칩의 0은 흐리지만 누를 수 있다. 직접 고르지 않았고 현재 화면이 비었으면 항목이 있는 첫 화면을 연다.
- 승인된 명령 작업은 채팅의 해당 도구 카드에서 상태·**출력**·**취소**를 본다.
- 입력창 위 막대는 컨텍스트 창 사용량, 맨 아래 막대는 계정의 **5시간 / 주간** 사용량이다. 보고되지 않은 구간은 보이지 않는다.

## 9. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 창에 WebView2 설치 안내가 나온다 | Microsoft Edge WebView2 Runtime을 설치하고 VS를 다시 연다 |
| 연결 점이 빨간색이다 | 점을 누르면 다시 연결한다. 계속되면 `⋯` > 다시 시작 |
| 연결 점이 "설정 필요"다 | 계정 탭에서 로그인하거나 API 키를 넣는다 |
| 원인을 알고 싶다 | `⋯` > 로그 보기 (`%LOCALAPPDATA%\Pomp\logs\pomp-vs.log`) |
| 화면 언어를 바꾸고 싶다 | 도구 > 옵션 > Pomp > 일반 > 채팅 > 언어 |

## 단축키 요약

| 키 | 동작 |
|---|---|
| `Shift+Alt+Q` / `Shift+Alt+N` | POMP 열기 / 새 대화 |
| `Shift+Alt+E` / `R` / `F` / `U` | 이 코드 설명 / 리뷰 / 고치기 / 테스트 작성 |
| `Shift+Alt+I` | 현재 파일을 채팅 컨텍스트에 추가 |
| `Alt+M` | POMP에게 질문 |
| `Alt+/` | 선택한 줄을 지식에 추가 |
| `Alt+J` | 편집기 ↔ 채팅 포커스 전환 |
